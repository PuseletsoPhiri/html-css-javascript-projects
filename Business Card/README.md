Business Card

A simple and responsive digital business card built with HTML and CSS.

Preview

This project displays a stylish business card featuring:
- A profile image
- Name and title
- Location
- Clean card layout using Flexbox

Technologies Used

- HTML5
- CSS3
- Flexbox
